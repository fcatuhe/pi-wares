# claude-code-use

Re-exports [`@benvargas/pi-claude-code-use`](https://github.com/ben-vargas/pi-packages/tree/main/packages/pi-claude-code-use) (Anthropic OAuth payload patching) from a named folder, because pointing `pi.extensions` straight at its `extensions/index.ts` leaves pi's `/config` selector labelling it a bare `index.ts`.
