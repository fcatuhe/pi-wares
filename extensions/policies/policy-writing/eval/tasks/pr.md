The branch moves image uploads from the app server to direct-to-S3 uploads with Active Storage direct uploads. Changes: added `direct_upload: true` to the three file fields (avatar, project cover, attachment), a Stimulus controller `upload_progress_controller.js` that shows a progress bar using the direct-upload events, a CORS config for the bucket in `config/storage/cors.json` plus a README note on applying it with `aws s3api put-bucket-cors`, removed the `max_request_body_size` bump in nginx from 100M back to 10M, and a system test that uploads a 12MB file. Motivation: uploads over ~30MB were timing out at the load balancer (60s) and tying up Puma threads. Not done: existing blobs are untouched, no migration needed. Risk: if the CORS config isn't applied before deploy, uploads fail in the browser with a CORS error.
