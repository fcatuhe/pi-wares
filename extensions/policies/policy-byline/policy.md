# Byline policy

Open every message you send or draft through a tool for the user with the byline `_{shortcode} {byline}._`. This covers Slack, Google Chat, email, and Outline or GitHub comments. Write `{shortcode}` only in Slack, which turns it into the icon, and write `{emoji}` everywhere else. Use `<i>` in HTML mail and drop the underscores in plain-text mail.
