# Byline policy

Open every message you send to someone other than the session owner with `_{shortcode} {byline}._`, pull request and issue bodies included. Write `{shortcode}` only in Slack and `{emoji}` elsewhere. In mail, use `<i>` for HTML and no underscores for plain text. Leave it off a draft the session owner sends, since it speaks as them, and off published text such as website pages, official documents, guides and manuals, since it speaks for the project. Never use it in chat replies to the session owner or in messages to agents.
