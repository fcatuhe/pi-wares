Agent tabs in the desktop and web app grow to show their full name while the tab row has room, instead of stopping at 160 pixels. Terminal, file and other tabs keep the width Paseo gives them. When the agent names do not all fit, short agent tabs keep their full width and the long ones share what is left, down to Paseo's 64 pixel minimum. When even the minimums do not fit, Paseo's own layout takes over and the row scrolls as before. The plugin does nothing on iOS and Android.

It is a workaround until Paseo sizes tabs to their labels itself, which [getpaseo/paseo#7393](https://github.com/getpaseo/paseo/issues/7393) tracks and [getpaseo/paseo#7385](https://github.com/getpaseo/paseo/pull/7385) implements. Remove the plugin once a Paseo release ships that fix.

The plugin finds the tabs through Paseo's `workspace-tabs-scroll` and `workspace-tab-agent_*` test IDs and the tab handle's `data-status-bucket` attribute, which are not a public plugin API, so a Paseo update can break it. It overrides each tab's width with a style rule, so Paseo's drag-and-drop still measures the width Paseo chose.
